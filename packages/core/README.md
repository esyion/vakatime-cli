# @esyion/vakatime-core

Pure TypeScript domain logic for Vakatime heartbeat normalization, AI-agent event adapters, duration summaries, project resolution, and usage analytics.

This package is used by `@esyion/vakatime` and the Vakatime web application.

## Install

```sh
npm install @esyion/vakatime-core
```

## Development

```sh
pnpm --filter @esyion/vakatime-core build
pnpm --filter @esyion/vakatime-core test
```
